# 🦁 Savanna Horizon Safaris

A modern, responsive web application and all-in-one booking portal built for **Savanna Horizon Safaris**, proudly based in the heart of Nairobi, Kenya.

![Savanna Horizon Banner](https://images.unsplash.com/photo-1516426122078-c23e76319801?auto=format&fit=crop&q=80&w=1200)

## ✨ Features

- **🌐 Interactive Navigation:** Quick links to Home, Destinations, Bookings, About Us, and Contact, complete with mobile-responsive dropdown menus.
- **🗺️ Featured Destinations:** Showcases iconic Kenyan wildlife parks, reserves, and coastal gems (Masai Mara, Amboseli, Diani Beach) with pricing and booking call-to-actions.
- **✈️ All-in-One Booking Portal:** Integrated tabbed interface allowing users to inquire about:
  - Safari Adventures & National Parks
  - Hotel & Resort Reservations
  - Local & International Flight Itineraries
- **📍 Nairobi-based Identity:** Features official Nairobi headquarters information, local contact lines, and tailored customer support channels.
- **🎨 Modern UI/UX:** Styled completely with **Tailwind CSS** and lightweight **Lucide React** icons.

---

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Language:** JavaScript (React)
